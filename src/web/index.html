Defensive Security Principles & Mathematical Models

1. Shannon Entropy Formula

Shannon entropy measures the average rate of information produced per character:

H = - ∑ [ p(x) * log₂(p(x)) ] (bits/character)
Total Shannon Entropy = Length * H (bits)

This model directly penalizes redundant characters (e.g., aaaaaa has 0 bits of Shannon entropy).

2. Keyspace Combinatorial Search Space

Brute force complexity depends on the character variety pool \(|R|\):

E = Length * log₂(|R|) (Keyspace bits)
Total Search Space = |R|^Length = 2^E

A full 95-character alphanumeric and symbol set yields \( \log_2(95) \approx 6.57 \) bits per character.
